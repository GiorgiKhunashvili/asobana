# Bundled assets

## Brand identity

The owner selected Asobana logo concept **01** on 2026-10-17: a rounded connected
**A**, with three terminals and a tracing path, in navy `#0B294B` and gold
`#E3B65A`. The original imagegen concept sheet and prompt remain under ignored
`artifacts/branding/asobana-logo-directions.*`. Production artwork is reconstructed
as clean vector paths; it is not a crop of the concept sheet.

- `icon.svg` and `icon.png`: app icon, also displayed above the Georgian title
  on the home screen. The PNG is 1024 × 1024 RGB without alpha or rounded outer
  corners; the platform applies its icon mask.
- `branding/mark-light.*` and `branding/mark-dark.*`: symbol for light/dark surfaces.
- `branding/mark-splash.*`: the dark symbol with its swipe in the app's night
  violet `#120C24`, for the launch splash (Android directly, iOS through
  `splash-lockup.png`, which `scripts/build-splash.py` builds from it).
- `branding/mark-mono.*` and `branding/mark-white.*`: single-colour cutout symbols.
- `branding/logo-light.*` and `branding/logo-dark.*`: horizontal symbol + Asobana
  wordmark for advertising. Letterforms are original vector paths, with no font
  dependency. All seven variants have SVG masters and transparent PNG exports.

Regenerate from the repository root with `node scripts/build-branding.cjs` in an
environment where the `sharp` Node package is available (including via `NODE_PATH`).
It also writes `artifacts/branding/asobana-01-production-preview.png`, including
96, 64, 48 and 32 px icon previews. The runtime uses the app icon PNG; the other
exports are available for advertising and design work.

## Game assets

`fonts/NotoSansGeorgian.ttf`: Noto Sans Georgian 2.005 variable font (wght 100–900,
wdth 62.5–100), obtained from
[Google Fonts](https://github.com/google/fonts/tree/main/ofl/notosansgeorgian).
It is the source for the shipped instances and is not loaded by the app.

`fonts/GeoText-Regular.ttf`, `GeoText-SemiBold.ttf`, `GeoText-Bold.ttf` and
`GeoDisplay-Black.ttf` (condensed, wdth 75): static instances cut from that font
with `scripts/instance-fonts.py` and renamed so each style registers under its own
PostScript name. They keep every Mkhedruli and Mtavruli code point. The source
carries no Reserved Font Name; copyright and the SIL Open Font License 1.1 are in
`fonts/OFL.txt` and apply to the instances. Fonts load from the app bundle before
any screen renders; no runtime font fetch is required. Regenerate from the repo root:

```sh
uv run --with fonttools python -I scripts/instance-fonts.py
```

`audio/*.wav`: three original synthesized sine tones generated for this prototype.
No third-party sound recordings, music or image assets are bundled.

`scenes/<chapter id>.jpg` and `scenes/<chapter id>-band.jpg`: ten painted Georgian
landscapes, one per chapter, generated by the project owner on 2026-10-15 with
ChatGPT image generation from the brief in `docs/SCENE_BRIEF.md`. The 1024 × 1536
PNG masters stay in the git-ignored `artifacts/scenes/`. `scripts/build-scenes.py`
compresses them (full-screen JPEG plus a horizon strip for chapter cards, about
2.9 MB in total). Each painting now belongs to the journey stop it shows (see
`STOP_PAINTINGS` in `src/theme/scenes.ts`).

`scenes/<stop id>.jpg` and `scenes/<stop id>-band.jpg` for the other 38 journey
stops: generated by Codex on 2026-10-17 with OpenAI's built-in image generation
(the tool does not name the exact model), text-only, one image per stop, from the
prompts in `artifacts/journey-paintings-brief.md`. Codex's per-stop review is in
`artifacts/scenes/journey-paintings-report.md`; Borjomi uses Codex's best
"candidate" (a spruce tip reaches the middle of the image, behind the board). The
PNG masters stay in `artifacts/scenes/` as `NN-<stop id>.png`; the same script
compresses them (about 8 MB more). The images are stylised impressions, not
architectural records.

Before an App Store release, confirm that both image tools' terms allow
commercial use, and keep the briefs as the record of the prompts.

`studio/spilo-games/`: the Spilo Games studio logo, concept 04D-3A, selected by
the owner on 2026-10-17 (`IMPLEMENTATION.txt` records the handoff and prompts).
`approved-reference-04D-3A.png` is the source of truth. The app uses
`spilo-games-ivory.png` (dark surfaces) and keeps `spilo-games-plum.png` for
light ones; both are exact cut-outs of the reference made by
`scripts/build-studio-logo.py`, which unmixes the single plum ink from the flat
lavender ground, so the letterforms and elephant match the approved artwork.
The generated `spilo-games-logo-transparent.png` differs in details (for example
the I's bars) and is not used. Regenerate from the repo root:

```sh
uv run --with pillow --with numpy python -I scripts/build-studio-logo.py
```

`branding/splash-lockup.png` and `branding/splash-name.png`: the launch lockup
(the mark above ასობანა in GeoDisplay, gold-light) for the native splash, and the
name alone for the loading view that follows it. Regenerate from the repo root
after changing the mark or the name:

```sh
uv run --with pillow python -I scripts/build-splash.py
```
