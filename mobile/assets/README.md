# Bundled assets

`fonts/NotoSansGeorgian.ttf`: Noto Sans Georgian variable font, obtained from
[Google Fonts](https://github.com/google/fonts/tree/main/ofl/notosansgeorgian).
Copyright and SIL Open Font License 1.1 are preserved in `fonts/OFL.txt`.
The font is loaded from the app bundle; no runtime font fetch is required.

`audio/*.wav`: three original synthesized sine tones generated for this prototype.
No third-party sound recordings, music or image assets are bundled.
