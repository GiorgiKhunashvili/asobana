# Development plan

## Milestone A

1. Inspect requirements/repository, establish boundaries and compatible Expo SDK.
2. Scaffold strict TypeScript, Router, lint/format, Jest/RNTL and Python/Pytest CI.
3. Define versioned shared models and engine-to-UI contract.
4. Validate Georgian vocabulary, grids, wheel multisets and content packs.
5. Implement immutable submission, hints, rewards, progression and wheel rules.
6. Add transactional SQLite migrations, restoration checks and queued Zustand IO.
7. Integrate temporary home/chapter/level/game/settings/shop screens with native
   UI-thread dragging, Skia path, accessible alternatives and platform effects.
8. Implement deterministic Python crossword generation and draft review reports.
9. Run engine, storage, component, generator, type/lint/format and Expo checks;
   verify startup/native gestures/restart when a runtime is available.
10. Update status, document exact results and hand off the presentation contract.

## Milestone B

- Reconcile the missing full product spec and approve final branding.
- Claude replaces temporary visuals using the stable public contract.
- Native interaction profiling and accessibility review on iOS and Android.
- Native-speaker editorial approval, dictionary licensing review and larger packs.
- Improve generator search/scoring and editorial tooling without auto-approval.
- Test migrations against released snapshots and interrupted-write scenarios.

## Later

Add advertising, purchases, analytics and optional online services only after
separate product decisions. No backend or monetization dependencies now.
