# Word explanations batch 01

This batch has draft Georgian explanations for the **149 words** the owner selected on 2026-10-30. All are pending owner review. The game shows the same text from [word-explanations.json](../content/word-explanations.json), so a correction must change both files.

## Limitations

- These are assistant drafts in Georgian. No native speaker has reviewed them.
- 135 meanings were checked on ganmarteba.ge on 2026-10-30. The other 14 have no matching entry there and rest on the recorded meaning and general knowledge.
- Dictionary text was used to check meanings, not copied. Some short facts, such as ბიცოლა or მაზლი, can only be said one way.
- Some details add general knowledge beyond the dictionary, such as ომბალო in ტყემალი, or the poem მერანი.
- Greek letters in ალფა and ბეტა need a check on a device, because the game font may not include them.
